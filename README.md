# Розклад занять групи КН01-23

Живий розклад: **https://vvprog.github.io/rozklad/**

Одна самодостатня HTML-сторінка — без збірки, без залежностей, без сервера.
Сітка тижня з чисельником/знаменником, підсвітка поточної пари, посилання на
Zoom і Google Classroom, експорт у календар, редагування прямо в браузері.

## Файли

| Файл | Роль |
|---|---|
| `index.html` | Те, що віддає GitHub Pages. Повний документ. **Тут живуть актуальні дані** — сторінка перезаписує цей файл сама. |
| `rozklad.html` | Джерело коду (CSS + JS) у вигляді фрагмента, який публікується як Artifact у Claude. |
| `build.py` | Збирає `index.html` з коду `rozklad.html` і даних із чинного `index.html`. |

```bash
python3 build.py
```

## Посилання під паролем

Сітка занять відкрита всім, а посилання на Zoom і Google Classroom, ідентифікатори
конференцій та коди доступу зашифровані: **AES-256-GCM**, ключ виводиться з пароля
групи через **PBKDF2-SHA256, 250 000 ітерацій**. У репозиторії лежить лише
шифротекст (`vault` у блоці даних) — відкритих посилань тут немає.

Хто знає пароль, натискає «Розблокувати» один раз, і браузер його запамʼятовує.
Змінити або зняти пароль: «Редагувати» → «Налаштування» → «Змінити пароль».
Редагувати розклад можна лише розблокованим — інакше збереження стерло б посилання.

Введений пароль зберігається у `localStorage` браузера і живе там без терміну
придатності. Кнопка **«Заблокувати»** у шапці прибирає його з цього пристрою
й повертає сторінку в закритий стан — натискайте її на чужому комп'ютері.

Забутий пароль відновити неможливо: посилання доведеться вводити заново.

## Як редагувати

**У браузері.** Відкрийте сайт → «Редагувати» → змініть пари → «Зберегти для всіх».
Перший раз сторінка попросить персональний токен GitHub — створіть
[fine-grained token](https://github.com/settings/personal-access-tokens/new)
з доступом до цього репозиторію та дозволом **Contents: Read and write**.
Токен зберігається лише у вашому браузері (`localStorage`) і ніколи не потрапляє
у файл сторінки. Після збереження GitHub Pages оновлює сайт приблизно за хвилину.

**У коді.** Дані лежать у `<script id="app-data" type="application/json">`
всередині `index.html` — звичайний JSON, який можна правити руками.

## Дані розкладу

Кожне заняття: `day` (0 = понеділок), `slot` (номер пари), `week`
(`both` / `num` — чисельник / `den` — знаменник), `subject`, `teacher`, `kind`,
`room`, `link`, `classroom`, `meetingId`, `passcode`, `note`.

Чисельник і знаменник рахуються від `weekStart` (понеділок першого тижня
семестру) та `firstWeek`. Ці поля — у «Налаштуваннях» на сторінці.
